# Sharing without an address bar

Cancelling native sharing leaves the garden and note available without an error.
When sharing or clipboard access fails, a labelled, read-only garden link is
available in the page. Focusing it selects the complete URL for manual copying,
including when the installed app has no browser address bar.

The browser journey checks cancellation, blocked clipboard access, the exact link,
focus retention and narrow layouts. Garden and image areas keep their existing
reserved dimensions; the reading-size control remains available.

- [Desktop](share-fallback-1440.png)
- [Phone](share-fallback-390.png)

Native share sheets are represented by controlled browser responses. Physical
share targets, display scaling and assistive technology remain device checks.
